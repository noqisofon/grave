# grave

vim 風コロンコマンドで遊ぶ古典的ローグライク。人間もAIエージェントも同じゲームを遊べる。

## 構成

- `core/` — ヘッドレスのゲームロジック。入力は `move west` のようなコロンコマンドの文字列だけ
- `tui/` — キーバインド層と描画（crossterm）。キーはコマンド文字列に展開するだけ
- `mcp/` — stdio の MCP サーバー。コマンドを受けてテキスト観測を返す

## 遊ぶ

```sh
cargo run -p grave-tui -- [seed]
```

| キー | 動作 |
| --- | --- |
| `h j k l` / 矢印 | 西 南 北 東 |
| `y u b n` | 北西 北東 南西 南東 |
| 敵のいる方向へ移動 | 攻撃（体当たり） |
| `q` + 文字 | 持ち物を使う（薬は飲む・巻物は読む。`:use a` と同じ） |
| `i` | 持ち物の一覧 |
| `>` | 階段を降りる |
| `_` | 既知の階段まで自動移動 (`travel >`) |
| `x` | 自動探索 (`explore`) |
| `z` | 待つ |
| `;` | 階段の位置を調べる |
| `3j` | 数字プレフィックスで反復 |
| `.` | 直前の行動を繰り返す |
| `:` | コロンコマンド (`Tab` 補完, `↑↓` 履歴, `;` で連続実行) |

`:map <1文字> <コマンド>` で再割り当て、`:unmap`、`:new [seed]` で最初からやり直し、`:q` で終了。

## ルール

- 地下へ降りていく。敵は **スライム** (`s`)。深く潜るほど数・HP・攻撃力が増える
- 敵はこちらが見えている間だけ近づいてきて、隣接すると攻撃してくる
- 敵に向かって `move` するか `attack <dir>` で攻撃。HP が 0 になるとゲームオーバー
- 敵が見えていない間は 10 ターンごとに HP が 1 回復する
- フロアには薬 (`!`) と巻物 (`?`) が落ちていて、上を歩くと自動で拾う。`explore` は拾いに行く
- 薬と巻物は最初は **未識別**（「赤い薬」「「ルク」の巻物」など）。見た目と効果の対応はゲームごとにランダムで、使うとその種類の正体が分かる
  - 薬: 回復の薬（HP+10）/ 毒の薬（5ダメージ。死ぬこともある）/ 眠りの薬（5ターン無防備）
  - 巻物: 識別の巻物（未識別の持ち物を1つ識別。`use c b` のように対象も選べる）/ 地図の巻物（フロアの地図が分かる）/ 転移の巻物（ランダムな場所へ）
- `explore` / `travel >` は、敵が見えている間は使えず、敵の出現・被弾・階段の発見で止まる

## エージェントから遊ぶ (MCP)

```sh
cargo build --release -p grave-mcp
claude mcp add grave -- ./target/release/grave-mcp
```

ツール: `command`（`;` 区切りで連続実行、失敗で停止）、`observe`、`new_game`（seed指定可）、`help`。
`command` には任意の `thought`（なぜその手を選んだか）を添えられる。
同じ seed と同じコマンド列は常に同じ結果になる。

## 記録と観戦

MCPサーバーは全ての行動を JSONL に追記する（既定は `grave-record.jsonl`。`--record <path>` で変更、`--no-record` で無効）。
1行1イベントで、`new_game`（seed）と `command`（コマンド・結果・`thought`・実行後の階/ターン）の2種類。
ゲームは seed とコマンド列から完全に再現できるので、マップは記録しない。

```sh
# 別の端末で、エージェントのプレイを観戦する
cargo run -p grave-tui -- --watch grave-record.jsonl
```

観戦側は記録を追いかけて同じゲームを再現し、`thought` を画面下部に表示する。
再現結果が記録とずれたら画面にそう出る。

## 冒険日誌

エージェントが自分のプレイを振り返って日誌を書く。

1. `journal` ツール: 記録から機械的にまとめた「素材」を返す（深さごとの出来事、倒した敵、最低HP、自分の `thought`、死因、ターンが進まなかったコマンドの数）
2. エージェントがその素材をもとに、自分の言葉で日誌を書く
3. `journal_write` ツール: 日誌を保存する（記録ファイルに追記される）

```sh
# 素材と、書かれた日誌を読む
cargo run -p grave-tui -- --journal grave-record.jsonl
```

観戦中 (`--watch`) に日誌が書かれると、`j` で読める。ゲームオーバー時には、エージェントに `journal` を促す一文が出る。
