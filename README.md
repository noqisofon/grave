# grave

AI エージェントも遊べるかもしれない古典的ローグライク。

vim 風コロンコマンドで遊ぶ。人間もAIエージェントも同じゲームを遊べる。

## 構成

- `core/` — ヘッドレスのゲームロジック。入力は `move west` のようなコロンコマンドの文字列だけ
- `tui/` — キーバインド層と描画（crossterm）。キーはコマンド文字列に展開するだけ
- `mcp/` — stdio の MCP サーバー。コマンドを受けてテキスト観測を返す

## 遊ぶ

```sh
cargo run -p grave-tui -- [seed]
```

| キー | 動作 |
| --- | --- |
| `h j k l` / 矢印 | 西 南 北 東 |
| `y u b n` | 北西 北東 南西 南東 |
| 敵のいる方向へ移動 | 攻撃（体当たり） |
| `q` + 文字 | 薬を飲む (`:quaff a`) |
| `E` + 文字 | 食べる (`:eat a`) |
| `F` | ランタンに油を継ぎ足す (`:refill`、油つぼの文字も選べる) |
| `a` / `Z` + 文字 + 向き | 杖を振る (`:zap c east` / `:zap c nearest`。自分に効く杖は向き不要) |
| `R` + 文字 | 巻物を読む (`:read a`、識別の巻物は `:read a b` で対象も選べる) |
| `e` + 文字 | 武器・防具を身につける (`:equip a`) |
| `r` + 文字 | 装備をはずす (`:unequip a`) |
| `d` + 文字 | 持ち物を足元に捨てる (`:drop a`、数も選べる `:drop a 3`) |
| `,` | 足元の物を1個拾う (`:pickup`、番号で選ぶ `:pickup 2`。別名 `:get`) |
| `i` | 持ち物の一覧 |
| `>` | 階段を降りる |
| `<` | 階段を登る (アミュレット所持時のみ。`ascend`) |
| `_` | 既知の階段まで自動移動 (`travel >`) |
| `x` | 自動探索 (`explore`) |
| `z` | 待つ |
| `` ` `` | `:` と同じ（コマンドラインを開く。打ちやすい方でよい） |
| `;` | 階段の位置を調べる |
| `3j` | 数字プレフィックスで反復 |
| `.` | 直前の行動を繰り返す |
| `:` | コロンコマンド (`Tab` 補完, `↑↓` 履歴, `;` で連続実行) |

`i`（`:inventory`）を実行したときだけ、持ち物がマップの右上に重なって出る（装備中は黄色）。`Esc` か `i` で閉じ、ほかのキーは閉じたうえでそのまま働く。観戦中 (`--watch`) も `i` で出し入れできる。

`:map <1文字> <コマンド>` で再割り当て、`:unmap`、`:new [seed]` で最初からやり直し、`:q` で終了。

## ルール

- 地下へ降りていく。深く潜るほど敵の数・HP・攻撃力が増え、新しい種類が現れる

  | 敵 | 記号 | 現れる階 | 特徴 |
  |---|---|---|---|
  | スライム | `s` | 1〜 | 基本の敵。HP 6、ダメージ 1〜2 |
  | コウモリ | `b` | 1〜 | HP 3 と脆いが、1ターンに2回動き、ときどきふらふら飛び回る |
  | ゴブリン | `g` | 2〜 | HP 9、ダメージ 2〜4 |
  | オーガ | `O` | 4〜 | HP 10、ダメージ 3〜6。2ターンに1回しか動けない |
  | 毒グモ | `S` | 3〜 | HP 5、ダメージ 1〜2。噛まれると半分の確率で毒を受ける |
  | アクアター | `a` | 3〜 | HP 7、ダメージ 1。殴られるたびに鎧が錆びて防御-1（防具保護の巻物で防げる） |
- 敵はこちらが見えている間だけ近づいてきて、隣接すると攻撃してくる
- `stay [ターン数]` でその場に留まる（数を省くと1ターン）。足元にアイテムがあれば拾う（`wait` は拾わない）。敵に襲われたり体力が危なくなったら途中で止まる
- 敵に向かって `move` するか `attack <dir>` で攻撃。HP が 0 になるとゲームオーバー
- 敵が見えていない間は 10 ターンごとに HP が 1 回復する
- **拾う・捨てる**: 歩いてマスに乗ると、そこにある物を自動で拾う（1マスに物は複数載ってよく、自動で拾うのは **1個だけ**）。`stay` も同じ。持ち物は `a`〜`z` の26枠なので、不要な物は `drop <文字> [数]` で足元に捨てる（1ターン。装備中の物は先に `unequip`）
  - 捨てた物には印が付き、**歩いても `stay` しても自動では拾われず、`explore` も寄らない**。拾い直すには `pickup`（別名 `get`、1ターン）を使う
  - 足元に物があると、観測と `look` に番号付きの一覧が出る（例: `足元: 1) 回復の薬  2) Okay Sword (捨てた)`）。印のない物が先、捨てた物があとに並ぶ。引数なしの `pickup` は 1 番を拾う。`pickup 2` のように番号を選べば、捨てた物も拾える。足元に物がない・番号が範囲外・持ち物が満杯のときは失敗し、ターンを使わない
  - 魔除けのアミュレットは今までどおり自動で拾う
- フロアには薬 (`!`) と巻物 (`?`) が落ちていて、上を歩くと自動で拾う。`explore` は拾いに行く
- 薬と巻物は最初は **未識別**（「赤い薬」「「ルク」の巻物」など）。見た目と効果の対応はゲームごとにランダムで、使うとその種類の正体が分かる
  - 使うと `黒い薬を飲んだ。これは盲目の薬だった！ …` の形で正体が分かる（以後は本名で表示。薬・巻物・キノコ共通）。持ち物の未識別の行には `(未識別)` が付く
  - 薬（良い）: 回復の薬（HP+10と解毒）/ 大回復の薬（HP+30。余ると最大HP+2。地下3階〜）/ 力の薬（腕力+1）/ レベルアップの薬 / 力回復の薬 / 加速の薬（25ターン）/ モンスター探知の薬（敵の位置が次の行動まで地図に出る）/ アイテム探知の薬（落ちている物の場所が分かる）/ 透明視認の薬 / 浮遊の薬 / 解毒の薬
  - 薬（悪い）: 混乱の薬 / 幻覚の薬 / 毒の薬（5ダメージと腕力-2。死ぬこともある）/ 盲目の薬 / 眠りの薬（5ターン無防備）。悪い薬は薬全体の3分の1以下
  - 巻物: 識別の巻物（未識別の持ち物を1つ識別。`read c b` のように対象も選べる）/ 地図の巻物 / 転移の巻物 / 武器強化の巻物・防具強化の巻物（身につけているものの攻撃・防御+1）/ 呪い解除の巻物（呪われた装備がはずせるようになる。欠点は残る）/ 防具保護の巻物（鎧が錆びなくなる）/ モンスター混乱の巻物（見えている敵）/ モンスター停止の巻物（2マス以内の敵）/ 怯えの巻物（見えている敵が逃げる）/ モンスター生成の巻物 / 怒りの巻物（階じゅうの敵が見えなくても追ってくる）/ 睡眠の巻物（読むと眠る）
  - **腕力**: 10 が基準で、2ごとに攻撃±1（観測の見出しに `腕力 10/10`）。毒の薬で下がり、力回復の薬で戻り、力の薬で最大値が上がる
  - 薬と巻物の効果は `core/src/item.rs` の表（`ITEMS`）にデータとして書いてある。新しい薬・巻物は、`ItemKind` と表に1行足すだけで増やせる
- **探知・光の表示について**: モンスター探知の薬と光の杖が地図に出す敵の位置は、使った瞬間のもの（そのコマンドの中で敵が動いたあとの位置とは、1ターンぶんずれることがある）。魔法による探知なので、幻覚中でも敵の本当の名前と記号が出る
- **杖** (`/`): `zap <文字> <向き|nearest>` で振る（1ターン）。薬や巻物と同じく **未識別**（「樫の杖」など）で、振ると正体が分かる。**使用回数（充填数）** があり、0 になると使えない（`zap` は失敗し、ターンも使わない）。残りの回数は `inventory` の各行（`c) 雷の杖 [残り4回]`）と、ステータス行の `杖残り[c:4]` に **識別前でも** 必ず出る。振るたびに `(残り3回)` と知らせ、尽きると「杖の魔力は尽きた」
  - 向きは 8 方向（`move` と同じ）か `nearest`（いちばん近い、見えている敵。見えなければ失敗して回数を使わない。狙った敵の先まで同じ向きに飛ぶので、雷や光は奥まで届く）。飛ぶ杖は壁の手前まで、最初の敵に当たる（雷だけは線上の全員に当たる）。混乱していると向きがずれることがある
  - 光（向きの先を照らして地図に書き込む。光の中の敵も教える）/ 魔法の矢 / 火 / 雷（貫通）/ 冷気（ダメージ＋敵を減速）/ 生命吸収（与えたダメージぶん自分が回復）/ 敵減速 / 敵加速（損）/ 透明化（損。敵が見えなくなる。透明視認なら見える）/ 変身（別の種類の敵に。HPの割合は保つ）/ 消去（敵の状態と特殊な力 = 毒・錆び・ふらつきを消す）/ 敵テレポート / 自分テレポート（向き不要）
  - 杖は 1 本ずつ別物で重ならず、捨てても拾い直しても残りの回数は変わらない
- **指輪** (`=`): `equip <文字>` ではめ、`unequip` ではずす。**指は2本**（スロットが2つ）。防御 / 腕力 / 器用さ（敵の攻撃を避ける）/ ダメージ増加 / 再生（敵がいても速く治る）/ 消化遅延 / 隠密（敵に気づかれる距離が縮む）/ 探索（罠を見つけやすい）/ 透明視認 / 装飾（効果なし）。強さは +1〜+3
  - 見た目は宝石の名前（「ルビーの指輪」など）で、種類はゲームごとにランダム。**はめて30ターン過ごす**か、識別の巻物で正体と強さが分かる（分かるまでも効果は効いている）。すでに種類を知っていれば、はめた瞬間に強さまで分かる
  - **呪い**: 強さが負の指輪（防御・腕力・器用さ・ダメージ増加の4種に1/4）と、必ず呪われた **怒らせる指輪**（階じゅうの敵が見えなくても寄ってくる）と **テレポート癖の指輪**（ときどきランダムに飛ばされる）。呪われた指輪は、はめた瞬間に呪いと正体が分かり、**外せず捨てられない**。呪い解除の巻物で外せるようになる（識別の巻物を使えば、はめる前に呪いが分かる）
  - 毎ターンの効果（再生・罠探し・テレポート癖・光源の燃料）は `core/src/game/rings.rs` の `tick_equipment` に1か所にまとめてある
- **光源と燃料**: 最初に **松明**（燃料1500）を装備している。燃料は1ターンごとに1減り、ステータス行の `光源:松明 燃料1500/1500`、`inventory` の `光源: …` 行、観測の持ち物欄に **いつも** 出る。残り100で「火が弱くなってきた」、0で燃え尽きて **視界が半径2に狭まる**（敵はこちらを見つけられるので不利）。自動移動は燃え尽きた瞬間に止まる(そのあとは暗いまま進める)
  - 床には松明 `~`（拾ったら `equip` で持ち替える。古い松明は持ち物に戻る）とランタン（燃料4000、地下3階〜）と **油つぼ** `~` が落ちている。ランタンは `refill`（キー `F`）で油つぼ1個ぶん（+1500）を継ぎ足せる。松明は継ぎ足せない。食べ物と同じ「減っていく資源」として扱う
- 武器 (`)`) と防具 (`[`) も落ちている。種類（短剣・剣・斧／革の鎧・鎖かたびら・板金鎧）は最初から分かるが、拾うたびに **個体** が違う。`equip <文字>` で身につける（武器と防具は1つずつ。付け替えもこれ）。1ターン使う。装備は薬と違って **重ならず**、1個ずつ別の文字に入る
  - 素手は攻撃 2〜4。武器の基本値: 短剣 3〜5 / 剣 4〜7 (地下2階〜) / 斧 5〜9 (地下3階〜)
  - 防具は敵のダメージを減らす（最低1）。基本値: 革の鎧 1 / 鎖かたびら 2 (地下2階〜) / 板金鎧 3 (地下4階〜)
  - **品質ランク（接頭辞）**: 名前の頭の語が品質を表し、攻撃・防御に補正が付く。深い階ほど上位ランクが出やすい（Ancient は地下8階〜）

    | ランク | 語の例 | 補正 |
    |---|---|---|
    | Common | Basic / Okay / Regular / Usual | なし |
    | Uncommon | Superior / Prime / First Rate | +1〜+2 |
    | Rare | Mystical / Sanctified / Glorious | +2〜+3 (地下3階〜) |
    | Ancient | Eldritch / Primeval / Legendary | +3〜+5 (地下8階〜) |
  - **接尾辞（`of X`）**: Uncommon 以上には特殊効果が付くことがある（Uncommon 30% / Rare 60% / Ancient 必ず）
    - 武器: `of the Vampire`（命中するたびにHP+1）/ `of Might`（攻撃+1）/ `of Vigor`（敵を倒すとHP+2）
    - 防具: `of Thorns`（殴ってきた敵に1ダメージ返す）/ `of Warding`（毒を受けない）
  - **呪い**: `of the Cataclysm`（武器。攻撃+3、ただし受けるダメージが1回ごとに+1。防御で減らして最低1にしたあとに足すので、重い鎧でも必ず受ける）と `of Famine`（防具。防御+2）は強いが呪われている。呪いは **装備して初めて分かる**（装備した瞬間に正体も分かる）。呪われた装備は `unequip` も `drop` もできず、同じ枠の別の装備にも替えられない（まだ身につけていない呪い装備は捨てられる）。Famine は満腹度も余計に減る（2ターンに1回、追加で1）
  - **識別**: 品質の語は見えるが、接尾辞と正確な補正値は **未識別**。名前に `(?)` が付く（例: `Sanctified Sword (?)`）。持ち物の行には分かる範囲だけが出る（例: `[攻撃 4〜7 +(2〜3)?]`）。次のどちらかで分かる
    - 識別の巻物を使う（`read c b`。装備にも使える。対象を省くと未識別のものから自動で選ぶ）
    - 装備したまま 50 ターン過ごす
  - `inventory` の各行には、名前・攻撃範囲または防御値・識別状態・装備中かどうかが出る。識別済みで装備していないものには、今の装備との差も出る（例: `Superior Sword [攻撃 5〜8 (装備比 +1〜+1)]`）
  - 観測の見出しの攻撃範囲と防御は、品質補正と接尾辞を含めた値
- **クリア条件**: 地下30階（最深部）の床にある魔除けのアミュレット `,` を手に入れ、階段を登って地上（地下1階の階段から `ascend`）まで持ち帰る。アミュレットを持つと階段は登り階段 `<` になり、`descend` はできない。階は登るたびに作り直される
- **レベル**: 敵を倒すと経験値（敵ごとの基本値＋(階−1)）を得る。累計 10 / 30 / 60 … (5×Lv×(Lv+1)) でレベルアップし、最大HP+4（その分回復）。2レベルごとに攻撃+1。レベルが上がると自動移動は止まる
- **満腹度**: 1ターンごとに減る（最大300、開始時250）。100 以下で空腹、30 以下でひどい空腹、0 になると毎ターン1ダメージで自然回復もしない。どの階にも食べ物が1つは落ちている
  - パン `%`（+150。6個に1個は腐っていて、毒を受ける）、干し肉（+100、地下2階〜）
  - キノコ `%` は薬や巻物と同じく **未識別**（「赤いキノコ」など。見た目と効果の対応はゲームごと）: 食用キノコ（+60）/ 毒キノコ（毒を受ける）/ 元気キノコ（HP+8、地下2階〜）
  - 食べるのは `eat <文字>`
- **毒**: 毒の間は1ターンごとに1ダメージで、自然回復しない。時間で抜けるほか、回復の薬・解毒の薬でも治る。毒グモに噛まれる、腐ったパンや毒キノコを食べると受ける
- **状態異常**: 毒・混乱・幻覚・盲目・睡眠・停止・加速・減速・浮遊・透明・透明視認がある。プレイヤーにも敵にも付き、残りターンが毎ターン減って、切れるとメッセージが出る。ステータス行と観測の「状態」欄に、残りターンと影響が出る（敵は一覧の横に `[混乱5]`）。記録（JSONL）の `command` には、付与と解除が `status_events`、実行後の状態が `statuses` として残る
  - 混乱: 移動・攻撃の向きがときどきずれる（壁にぶつかってもターンを使う）。自動移動は不可
  - 幻覚: 敵の名前と記号がターンごとにでたらめになる（HPと位置は本物。観測の見出しにそう書かれる）
  - 盲目: 観測にマップも敵も出ない（そう明記される）。襲われても「何かの攻撃！」。巻物は読めない。新しい場所も覚えない。自動移動は不可
  - 睡眠・停止: 行動できず、解けるまで時間が過ぎる（襲われても起きない）
  - 加速: 2回行動して世界が1ターン進む。減速: 1回の行動で2ターン進む
  - 浮遊: 罠を無視する。透明: 敵は2マス以内に来るまでこちらに気づかない。透明視認: 透明な敵が見える
  - 敵の状態: 混乱・盲目（ふらふら動く）/ 睡眠・停止（動かない）/ 加速・減速（行動が倍・半分）/ 怯え（逃げる。追い詰められると戦う）/ 激怒（見えない場所からでも追ってくる）/ 毒（毎ターン1ダメージ。倒すと経験値）/ 透明（姿が見えない）
- **罠**: 各階に隠れた罠がある（落とし穴 = 1〜3ダメージで下の階へ。最深部とアミュレット所持中には出ない / 毒矢 = 2ダメージと毒 / 眠りガス）。踏むと発動し、`^` で表示される。隣に立っていると見つかることもある。見つけた罠は `explore` / `travel` が避ける。浮遊中は発動しない
  - **解除**: `disarm [向き]`（1ターン。向きは隣のマス、省くと足元）で、見つけた罠を確率で解除できる。成功率は約60%（器用さの指輪で上がり、混乱で下がる。10〜95%）。失敗すると3回に1回は罠が作動する（隣の落とし穴は、落ちずに済む）。隠れた罠や、盲目のときは使えない
- `explore` / `travel >` は、敵が見えている間は使えず、敵の出現・被弾・階段の発見・空腹の知らせ・体力が危ないとき（毒や飢え）で止まる

## エージェントから遊ぶ (MCP)

```sh
cargo build --release -p grave-mcp
claude mcp add grave -- ./target/release/grave-mcp
```

ツール: `command`（`;` 区切りで連続実行、失敗で停止）、`observe`、`new_game`（seed指定可）、`help`。
`command` には任意の `thought`（なぜその手を選んだか）を添えられる。
同じ seed と同じコマンド列は常に同じ結果になる。

## 記録と観戦

MCPサーバーは全ての行動を JSONL に追記する（既定は `grave-record.jsonl`。`--record <path>` で変更、`--no-record` で無効）。
1行1イベントで、`new_game`（seed）と `command`（コマンド・結果・`thought`・実行後の階/ターン）の2種類。
ゲームは seed とコマンド列から完全に再現できるので、マップは記録しない。
ただし再現できるのは **同じルールのとき** だけ。`new_game` には `rules`（ルールの版）も入り、観戦側は今のコードの版と違う記録に「古いルールの記録」と出す。
ルールを変える開発者へ: 敵・アイテム・マップの生成やダメージ計算を変えたら `core/src/record.rs` の `RULES_VERSION` を上げる。ソフトウェアのバージョン x.y.z の z（ルートの `Cargo.toml`）も同じ値に合わせる（テスト `software_patch_version_matches_rules_version` が確かめる）（上げ忘れはテスト `rules_version_matches_golden_run` が知らせる）。

```sh
# 別の端末で、エージェントのプレイを観戦する
cargo run -p grave-tui -- --watch grave-record.jsonl
```

観戦側は記録を追いかけて同じゲームを再現し、`thought` を画面下部に表示する。
再現結果が記録とずれたら画面にそう出る。

## 冒険日誌

エージェントが自分のプレイを振り返って日誌を書く。

1. `journal` ツール: 記録から機械的にまとめた「素材」を返す（深さごとの出来事、倒した敵、最低HP、自分の `thought`、死因、ターンが進まなかったコマンドの数）
2. エージェントがその素材をもとに、自分の言葉で日誌を書く
3. `journal_write` ツール: 日誌を保存する（記録ファイルに追記される）

```sh
# 素材と、書かれた日誌を読む
cargo run -p grave-tui -- --journal grave-record.jsonl
```

観戦中 (`--watch`) に日誌が書かれると、`j` で読める。ゲームオーバー時には、エージェントに `journal` を促す一文が出る。
