# grave

AI エージェントも遊べるかもしれない古典的ローグライク。

vim 風のコロンコマンドで遊ぶ。人間も AI エージェントも、同じゲームを同じコマンドで遊べる。
目標は、地下 30 階の魔除けのアミュレットを手に入れて、地上まで持ち帰ること。

- [構成](#構成) / [遊ぶ](#遊ぶ) / [ルール](#ルール) / [エージェントから遊ぶ (MCP)](#エージェントから遊ぶ-mcp) / [記録と観戦](#記録と観戦) / [冒険日誌](#冒険日誌)

## 構成

| ディレクトリ | 役割                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| `core/`      | ヘッドレスのゲームロジック。入力は `move west` のようなコロンコマンドの文字列だけ |
| `tui/`       | キーバインド層と描画（crossterm）。キーはコマンド文字列に展開するだけ        |
| `mcp/`       | stdio の MCP サーバー。コマンドを受けてテキスト観測を返す                    |

## 遊ぶ

```sh
cargo run -p grave-tui -- [seed]
```

同じ seed と同じコマンド列は、必ず同じ結果になる。終了時に seed が表示される。

| ------------------------ | ----------------------------------------------------------------- | ------------------------------ |

| `y u b n`                | 北西 北東 南西 南東に移動                                         | `move northwest` など          |
| `Home` `PgUp` `End` `PgDn` | テンキーの斜め移動（北西 北東 南西 南東）                       |                                |
| `KeypadBegin`（テンキー5） | 待つ                                                            | `wait`                         |
| 敵のいる方向へ移動       | 攻撃（体当たり）                                                  |                                |
| `>` / `<`                | 階段を降りる / 登る（`<` はアミュレット所持時のみ）               | `descend` / `ascend`           |
| `_`                      | 既知の階段まで自動移動                                            | `travel >`                     |
| `x`                      | 自動探索                                                          | `explore`                      |
| `z`                      | 1 ターン待つ                                                      | `wait`                         |
| `i`                      | 持ち物の一覧                                                      | `inventory`                    |
| `;`                      | 階段・敵・罠・足元の物を調べる                                    | `look`                         |
| `,`                      | 足元の物を 1 個拾う                                               | `pickup [番号]`（別名 `get`）  |
| `q` + 文字               | 薬を飲む                                                          | `quaff a`                      |
| `e` + 文字               | 食べる                                                            | `eat a`                        |
| `r` + 文字               | 巻物を読む（識別の巻物は `read a b` で対象も選べる）              | `read a`                       |

| `R` / `T` + 文字         | 装備をはずす                                                      | `unequip a`                    |
| `a` / `Z` + 文字 + 向き  | 杖を振る（自分に効く杖は向き不要）                                | `zap c east` / `zap c nearest` |

| `3j`                     | 数字プレフィックスで反復                                          |                                |
| `.`                      | 直前のキー操作を繰り返す                                          |                                |

### コマンドライン

- `Tab` で補完、`↑` `↓` で履歴、`;` で連続実行（失敗した時点で止まる）。
- 編集キー: `Ctrl+W` で直前の 1 語、`Ctrl+U` で行全体を消す。`Ctrl+H` は Backspace と同じ。
- 通常モードでは Ctrl や Alt を押しながらのキーは何もしない（`Ctrl+L` が東への移動になったりしない）。`Ctrl+C` はこれまでどおり終了。
- `q` `e` `r` `w` `R` `T` `a` `d` などのキーは、`:quaff ` のようにコマンドラインを開き、対象の候補を一覧で出す。文字を打って Enter で実行する。
- `:e` のようにコマンド名だけで Enter を押しても、エラーにはならず「どれを食べる？」の候補が出る。
- `i`（`:inventory`）を実行したときだけ、持ち物がマップの右上に重なって出る（装備中は黄色）。`↑` `↓` `PgUp` `PgDn` `Home` `End` で一覧をスクロールでき（観戦中も同じ）、`Esc` か `i` で閉じる。ほかのキーは閉じたうえでそのまま働く。
- `:map <1文字> <コマンド>` で再割り当て、`:unmap <1文字>`、`:new [seed]`（別名 `:new_game`）で最初からやり直し、`:help` で全画面のヘルプ（`↑` `↓` `PgUp` `PgDn` `Home` `End` でスクロール、`Esc` か `q` で戻る。キー操作とコマンド一覧が読める）、`:quit` で終了。
- `:q` は終了ではなく `quaff` の略。

## ルール

### 基本

- 地下へ降りていく。深く潜るほど敵の数・HP・攻撃力が増え、新しい種類が現れる。
- 敵はこちらが見えている間だけ近づいてきて、隣接すると攻撃してくる。
- 敵に向かって `move` するか `attack <dir>` で攻撃。HP が 0 になるとゲームオーバー。
- 敵が見えていない間は 10 ターンごとに HP が 1 回復する（毒・飢餓中は回復しない）。
- `stay [回数]` でその場に留まる（数を省くと 1 回、上限 1000。`wait` を回数ぶん繰り返すのと同じで、加速中は半分、減速中は倍の時間が過ぎる）。足元の物は拾う（`wait` は拾わない）。襲われたり体力が危なくなったら途中で止まる。
- `explore` / `travel >` は、敵が見えている間は使えない。敵の出現・被弾・階段の発見・空腹の知らせ・体力の危機（毒や飢え）・レベルアップで止まる。混乱・盲目の間も使えない。

### 敵

| 敵         | 記号 | 現れる階 | 特徴                                                                       |
| ---------- | ---- | -------- | -------------------------------------------------------------------------- |
| スライム   | `s`  | 1〜      | 基本の敵。HP 6、ダメージ 1〜2                                              |
| コウモリ   | `b`  | 1〜      | HP 3 と脆いが、1 ターンに 2 回動き、ときどきふらふら飛び回る               |
| ゴブリン   | `g`  | 2〜      | HP 9、ダメージ 2〜4                                                        |
| 毒グモ     | `S`  | 3〜      | HP 5、ダメージ 1〜2。噛まれると半分の確率で毒を受ける                      |
| アクアター | `a`  | 3〜      | HP 7、ダメージ 1。殴られるたびに鎧が錆びて防御 -1（防具保護の巻物で防げる）|
| オーガ     | `O`  | 4〜      | HP 10、ダメージ 3〜6。2 ターンに 1 回しか動けない                          |

HP は深い階ほど増える。

### レベルと満腹度

- **レベル**: 敵を倒すと経験値（敵ごとの基本値 + (階 − 1)）を得る。累計 10 / 30 / 60 … (5×Lv×(Lv+1)) でレベルアップし、最大 HP +4（その分回復）。2 レベルごとに攻撃 +1。
- **腕力**: 10 が基準で、2 ごとに攻撃 ±1。毒の薬で下がり、力回復の薬で戻り、力の薬で最大値が上がる。
- **満腹度**: 1 ターンごとに減る（最大 300、開始時 250）。100 以下で空腹、30 以下でひどい空腹、0 で毎ターン 1 ダメージ。どの階にも食べ物が 1 つは落ちている。
  - パン `%`（+150。6 個に 1 個は腐っていて毒を受ける）、干し肉（+100、地下 2 階〜）。
  - キノコ `%` は **未識別**: 食用キノコ（+60）/ 毒キノコ（毒を受ける）/ 元気キノコ（HP +8、地下 2 階〜）。
- **毒**: 毎ターン 1 ダメージで、自然回復しない。時間で抜けるほか、回復の薬・解毒の薬で治る。毒グモ・腐ったパン・毒キノコ・毒矢の罠で受ける。

### 持ち物

- 持ち物は `a`〜`z` の 26 枠。歩いてマスに乗ると、そこにある物を **1 個だけ** 自動で拾う（`stay` も同じ）。
- `drop <文字> [数]`（1 ターン、装備中の物は先に `unequip`）で捨てた物には印が付き、歩いても `stay` しても自動では拾われず、`explore` も寄らない。拾い直すには `pickup [番号]`（1 ターン）。
- 足元に物があると、観測と `look` に番号付きの一覧が出る（例: `足元: 1) 回復の薬  2) Okay Sword (捨てた)`）。印のない物が先、捨てた物があと。
- 足元に物がない・番号が範囲外・持ち物が満杯のときは失敗し、ターンを使わない。
- 魔除けのアミュレットは常に自動で拾う。

### 薬と巻物

薬と巻物は最初は **未識別**（「赤い薬」「「ルク」の巻物」など）。見た目と効果の対応はゲームごとにランダムで、使うとその種類の正体が分かる（以後は本名で表示。キノコ・杖・指輪も同様）。持ち物の未識別の行には `(未識別)` が付く。

- **薬（良い）**: 回復（HP +10 と解毒）/ 大回復（HP +30、余ると最大 HP +2、地下 3 階〜）/ 力 / レベルアップ / 力回復 / 加速（25 ターン）/ モンスター探知 / アイテム探知 / 透明視認 / 浮遊 / 解毒
- **薬（悪い）**: 混乱 / 幻覚 / 毒（5 ダメージと腕力 −2。死ぬこともある）/ 盲目 / 眠り（5 ターン無防備）。悪い薬は薬全体の 3 分の 1 以下。
- **巻物**: 識別（未識別の持ち物を 1 つ識別）/ 地図 / 転移 / 武器強化・防具強化（身につけているものの攻撃・防御 +1）/ 呪い解除（呪われた装備がはずせるようになる。欠点は残る）/ 防具保護（鎧が錆びなくなる）/ モンスター混乱 / モンスター停止（2 マス以内）/ 怯え / モンスター生成 / 怒り（階じゅうの敵が追ってくる）/ 睡眠（読むと眠る）
- モンスター探知の薬と光の杖が地図に出す敵の位置は、使った瞬間のもの。魔法による探知なので、幻覚中でも本当の名前と記号が出る。
- 薬と巻物の効果は `core/src/item.rs` の表（`ITEMS`）にデータとして書いてある。新しい薬・巻物は、`ItemKind` と表に 1 行足すだけで増やせる。

### 杖 (`/`)

`zap <文字> <向き|nearest>` で振る（1 ターン）。**使用回数（充填数）** があり、0 になると使えない（ターンも使わない）。残りの回数は `inventory` の各行（`c) 雷の杖 [残り4回]`）とステータス行の `杖残り[c:4]` に、識別前でも必ず出る。杖は 1 本ずつ別物で重ならず、捨てても拾い直しても残りの回数は変わらない。

- 向きは 8 方向（`move` と同じ）か `nearest`（いちばん近い、見えている敵。見えなければ失敗して回数を使わない）。飛ぶ杖は壁の手前まで、最初の敵に当たる（雷だけは線上の全員に当たる）。混乱していると向きがずれることがある。
- 種類: 光（向きの先を照らして地図に書き込む）/ 魔法の矢 / 火 / 雷（貫通）/ 冷気（ダメージ + 敵を減速）/ 生命吸収 / 敵減速 / 敵加速（損）/ 透明化（損。透明視認なら見える）/ 変身（HP の割合は保つ）/ 消去（敵の状態と特殊な力を消す）/ 敵テレポート / 自分テレポート（向き不要）

### 装備

武器 (`)`) と防具 (`[`) は、種類（短剣・剣・斧 / 革の鎧・鎖かたびら・板金鎧）は最初から分かるが、拾うたびに **個体** が違う。`equip <文字>` で身につける（武器と防具は 1 つずつ。付け替えもこれ。1 ターン）。装備は重ならず、1 個ずつ別の文字に入る。

- 素手は攻撃 2〜4。武器の基本値: 短剣 3〜5 / 剣 4〜7（地下 2 階〜）/ 斧 5〜9（地下 3 階〜）。
- 防具は敵のダメージを減らす（最低 1）。基本値: 革の鎧 1 / 鎖かたびら 2（地下 2 階〜）/ 板金鎧 3（地下 4 階〜）。
- **品質ランク**: 名前の頭の語が品質を表し、攻撃・防御に補正が付く。深い階ほど上位ランクが出やすい。

  | ランク   | 語の例                           | 補正               |
  | -------- | -------------------------------- | ------------------ |
  | Common   | Basic / Okay / Regular / Usual   | なし               |
  | Uncommon | Superior / Prime / First Rate    | +1〜+2             |
  | Rare     | Mystical / Sanctified / Glorious | +2〜+3（地下 3 階〜）|
  | Ancient  | Eldritch / Primeval / Legendary  | +3〜+5（地下 8 階〜）|

- **接尾辞（`of X`）**: Uncommon 以上には特殊効果が付くことがある（Uncommon 30% / Rare 60% / Ancient 必ず）。
  - 武器: `of the Vampire`（命中するたびに HP +1）/ `of Might`（攻撃 +1）/ `of Vigor`（敵を倒すと HP +2）
  - 防具: `of Thorns`（殴ってきた敵に 1 ダメージ返す）/ `of Warding`（毒を受けない）
- **呪い**: `of the Cataclysm`（武器。攻撃 +3、ただし受けるダメージが 1 回ごとに +1。防御で減らして最低 1 にしたあとに足す）と `of Famine`（防具。防御 +2、満腹度が 2 ターンに 1 回、余計に 1 減る）は強いが呪われている。
  - 呪いは **装備して初めて分かる**（装備した瞬間に正体も分かる）。
  - 呪われた装備は `unequip` も `drop` もできず、同じ枠の別の装備にも替えられない（まだ身につけていない呪い装備は捨てられる）。呪い解除の巻物ではずせるようになる。
- **識別**: 品質の語は見えるが、接尾辞と正確な補正値は未識別で、名前に `(?)` が付く（例: `Sanctified Sword (?)`）。持ち物の行には分かる範囲だけが出る（例: `[攻撃 4〜7 +(2〜3)?]`）。識別の巻物（`read c b`）か、装備したまま 50 ターン過ごすと分かる。
- `inventory` の各行には、名前・攻撃範囲または防御値・識別状態・装備中かどうかが出る。識別済みで装備していないものには、今の装備との差も出る（例: `[攻撃 5〜8 (装備比 +1〜+1)]`）。観測の見出しの攻撃範囲と防御は、品質補正と接尾辞を含めた値。

### 指輪 (`=`)

`equip <文字>` ではめ、`unequip` ではずす。**指は 2 本**。防御 / 腕力 / 器用さ（敵の攻撃を避ける）/ ダメージ増加 / 再生（敵がいても速く治る）/ 消化遅延 / 隠密（敵に気づかれる距離が縮む）/ 探索（罠を見つけやすい）/ 透明視認 / 装飾（効果なし）。強さは +1〜+3。

- 見た目は宝石の名前で、種類はゲームごとにランダム。**はめて 30 ターン過ごす**か、識別の巻物で正体と強さが分かる（分かるまでも効果は効いている）。すでに種類を知っていれば、はめた瞬間に強さまで分かる。
- **呪い**: 強さが負の指輪（防御・腕力・器用さ・ダメージ増加の 4 種に 1/4）と、必ず呪われた **怒らせる指輪**（階じゅうの敵が寄ってくる）と **テレポート癖の指輪**（ときどき飛ばされる）。呪われた指輪ははめた瞬間に呪いと正体が分かり、**外せず捨てられない**。呪い解除の巻物で外せるようになる。
- 毎ターンの効果（再生・罠探し・テレポート癖・光源の燃料）は `core/src/game/rings.rs` の `tick_equipment` に 1 か所にまとめてある。

### 光源

最初に **松明**（燃料 1500）を装備している。燃料は 1 ターンごとに 1 減り、ステータス行の `光源:松明 燃料1500/1500` や `inventory` に常に出る。残り 100 で「火が弱くなってきた」、0 で燃え尽きて **視界が半径 2 に狭まる**（敵はこちらを見つけられるので不利）。

- 床には松明 `~`（拾ったら `equip` で持ち替える。古い松明は持ち物に戻る）、ランタン（燃料 4000、地下 3 階〜）、**油つぼ** `~` が落ちている。
- ランタンは `refill`（キー `F`）で油つぼ 1 個ぶん（+1500）を継ぎ足せる。松明は継ぎ足せない。

### 状態異常

毒・混乱・幻覚・盲目・睡眠・停止・加速・減速・浮遊・透明視認がある。プレイヤーにも敵にも付き、残りターンが毎ターン減って、切れるとメッセージが出る。ステータス行と観測の「状態」欄に残りターンと影響が出る（敵は一覧の横に `[混乱5]`）。

- **混乱**: 移動・攻撃の向きがときどきずれる（壁にぶつかってもターンを使う）。自動移動は不可。
- **幻覚**: 敵の名前と記号がターンごとにでたらめになる（HP と位置は本物）。
- **盲目**: マップも敵も見えない。襲われても「何かの攻撃！」。巻物は読めない。新しい場所も覚えない。自動移動は不可。
- **睡眠・停止**: 行動できず、解けるまで時間が過ぎる（襲われても起きない）。
- **加速**: 2 回行動して世界が 1 ターン進む。**減速**: 1 回の行動で 2 ターン進む。
- **浮遊**: どの罠にもかからない。**透明視認**: 透明な敵が見える。
- **敵の状態**: 混乱・盲目（ふらふら動く）/ 睡眠・停止（動かない）/ 加速・減速 / 怯え（逃げる。追い詰められると戦う）/ 激怒（見えない場所からでも追ってくる）/ 毒（倒すと経験値）/ 透明（姿が見えない）。

### 罠

各階に隠れた罠がある。踏むと発動し、見つけると `^` で表示される。隣に立っていると見つかることもある。見つけた罠は `explore` / `travel` が避ける。浮遊中はどの罠も発動しない。

| 罠         | 効果                                                           |
| ---------- | -------------------------------------------------------------- |
| 落とし穴   | 1〜3 ダメージで下の階へ。最深部とアミュレット所持中には出ない |
| 毒矢       | 2 ダメージと毒                                                 |
| 眠りガス   | 眠る                                                           |

**解除**: `disarm [向き]`（1 ターン）で、見つけた罠を確率で解除できる。

- 向きは隣のマス。省くと足元、足元になければ隣の罠が 1 つだけのときそれ（複数あれば向きを聞かれる）。
- 成功率は約 60%（器用さの指輪で上がり、混乱で下がる。10〜95%）。
- 失敗すると 3 回に 1 回は罠が作動する。隣の落とし穴は落ちずに済む。浮遊中でも、手元が狂うと毒矢と眠りガスは作動する（落とし穴は浮いていれば落ちない）。
- 隠れた罠や、盲目のときは使えない。

### クリア条件

地下 30 階の床にある魔除けのアミュレット `,` を手に入れ、階段を登って地上（地下 1 階の階段から `ascend`）まで持ち帰る。アミュレットを持つと階段は登り階段 `<` になり、`descend` はできない。階は登るたびに作り直される。

## エージェントから遊ぶ (MCP)

```sh
cargo build --release -p grave-mcp
claude mcp add grave -- ./target/release/grave-mcp
```

| ツール          | 内容                                                                 |
| --------------- | -------------------------------------------------------------------- |
| `command`       | コマンドを実行（`;` 区切りで連続実行、失敗で停止）。任意の `thought`（なぜその手を選んだか）を添えられる |
| `observe`       | 現在のマップ・状態・敵・足元・持ち物・ログ（ターンを使わない）       |
| `new_game`      | 新しいゲーム（seed 指定可）                                          |
| `help`          | コマンド一覧                                                         |
| `journal`       | 冒険日誌の素材を返す                                                 |
| `journal_write` | 書いた日誌を保存する                                                 |

同じ seed と同じコマンド列は常に同じ結果になる。

## 記録と観戦

MCP サーバーは全ての行動を JSONL に追記する（既定は `grave-record.jsonl`。`--record <path>` で変更、`--no-record` で無効）。

- 1 行 1 イベントで、`new_game`（seed）、`command`（コマンド・結果・`thought`・実行後の階/ターン/HP・状態の付与と解除）、`journal` の 3 種類。
- ゲームは seed とコマンド列から完全に再現できるので、マップは記録しない。
- 再現できるのは **同じルールのとき** だけ。`new_game` には `rules`（ルールの版）も入り、観戦側は今のコードの版と違う記録に「古いルールの記録」と出す。

```sh
# 別の端末で、エージェントのプレイを観戦する
cargo run -p grave-tui -- --watch grave-record.jsonl
```

観戦側は記録を追いかけて同じゲームを再現し、`thought` を画面下部に表示する（`i` で持ち物、`q` で終了）。再現結果が記録とずれたら画面にそう出る。

**ルールを変える開発者へ**: 敵・アイテム・マップの生成やダメージ計算を変えたら、`core/src/record.rs` の `RULES_VERSION` を上げる。ソフトウェアのバージョン x.y.z の z（ルートの `Cargo.toml`）も同じ値に合わせる。z の不一致はテスト `software_patch_version_matches_rules_version` が、上げ忘れはテスト `rules_version_matches_golden_run` が知らせる。

## 冒険日誌

エージェントが自分のプレイを振り返って日誌を書く。

1. `journal` ツール: 記録から機械的にまとめた「素材」を返す（深さごとの出来事、倒した敵、最低 HP、自分の `thought`、死因、ターンが進まなかったコマンドの数）。
2. エージェントがその素材をもとに、自分の言葉で日誌を書く。
3. `journal_write` ツール: 日誌を保存する（記録ファイルに追記される）。

```sh
# 素材と、書かれた日誌を読む
cargo run -p grave-tui -- --journal grave-record.jsonl
```

観戦中 (`--watch`) に日誌が書かれると、`j` で読める。
